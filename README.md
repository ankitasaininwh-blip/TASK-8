# Laundry Services Hamburger Menu

## Task
Develop a responsive hamburger menu for the Laundry Services web app using only HTML and CSS.

## Features
- Responsive mobile navigation bar
- Hamburger menu icon visible only on mobile view
- Right-side menu panel
- Menu opens using CSS `:focus` pseudo-class
- Menu contains Home, Services, About Us and Contact Us
- No JavaScript or Bootstrap used
